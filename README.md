# redflag

Учебный веб-прототип на Streamlit: находит препятствия на дороге в записанном видео и показывает водителю предупреждение.

## Цель

Проверить, насколько готовая модель YOLOv8n подходит для поиска препятствий на дороге (животные, люди, транспорт) и как её качество меняется днём, ночью и в тумане.

## Подход

1. Пользователь работает с записанным видео через веб-интерфейс на Streamlit.
2. Готовая модель YOLOv8n ищет на кадрах животных, людей и транспорт.
3. При обнаружении препятствия прототип показывает предупреждение.
4. Качество оценивается отдельно для дня, ночи и тумана: precision, recall и матрица ошибок.

## Ограничения

- Прототип работает с записанным видео. Работа с живой камерой и в автомобиле не входит в проект.
- Прототип учебный и не предназначен для использования за рулём.
- Качество в разных условиях ещё не измерено.
- Модель находит только те классы, на которых её обучили. Если нужного животного нет среди её классов, она не сможет определить его правильно.
