# redflag

Streamlit негізіндегі оқу веб-прототипі: жазып алынған бейнеден жолдағы кедергілерді тауып, жүргізушіге ескерту көрсетеді.

## Мақсаты

Дайын YOLOv8n моделінің жолдағы кедергілерді (жануарлар, адамдар, көлік) табуға қаншалықты жарамды екенін және оның сапасы күндіз, түнде және тұманда қалай өзгеретінін тексеру.

## Тәсіл

1. Пайдаланушы жазып алынған бейнемен Streamlit веб-интерфейсі арқылы жұмыс істейді.
2. Дайын YOLOv8n моделі кадрлардан жануарларды, адамдарды және көлікті іздейді.
3. Кедергі табылғанда прототип ескерту көрсетеді.
4. Сапа күндіз, түнде және тұманда бөлек бағаланады: precision, recall және қателер матрицасы.
