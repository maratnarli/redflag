Модельді командаға тапсыру

1. Дайын файлдар

src/detector.py — YOLOv8n моделі және CLAHE.
requirements.txt — жергілікті ортада орнатылған кітапхана нұсқалары.
results/threshold_tuning.md — шекті таңдау және салыстыру нәтижелері.
check_model.py — бір бейне кадрында модельді тексеру.
prepare_tune.py — баптау бейнелерінен кадр алу.
compare_thresholds.py — үш сенімділік шегін салыстыру.
compare_clahe.py — CLAHE қосылған және өшірілген нұсқаларды салыстыру.

2. 3-қатысушыға: модельді қолдану

Python кодында:

from src.detector import detect
detections = detect(frame, conf=0.25, use_clahe=False)

frame — OpenCV арқылы оқылған BGR кескіні.

Нәтиже — сөздіктер тізімі:
label — нысан класының ағылшынша атауы.
conf — модельдің сенімділік мәні.
box — бастапқы кескіндегі (x1, y1, x2, y2) пиксель координаттары.

Нысан табылмаса, бос тізім қайтарылады.

Модель CPU-да жұмыс істейді. Бірінші шақыруда жүктеледі,
келесі шақыруларда сол модель қайта қолданылады.
yolov8n.pt файлы жоқ болса, алғашқы жүктеу үшін интернет қажет.

11.11.2026 бастап функцияның әдепкі параметрі conf=0.25 (бұған дейін conf=0.4 болған).
Баптау кезінде таңдалған шек — 0.25.
Сондықтан шақыру кезінде conf=0.25 параметрін анық беру керек.

CLAHE қосу үшін use_clahe=True беріледі.
Негізгі нұсқада әзірге use_clahe=False қолданылады.

Модель нысандарды анықтайды, бірақ қауіп туралы шешім қабылдамайды.
Жүргізуші жолағын және қауіпті анықтау — src/alert.py міндеті.

Өз көлігінің капоты car ретінде анықталуы мүмкін.
Ескерту логикасында оны алдағы кедергімен шатастырмау керек.

3. 4-қатысушыға: бағалау

Екі нұсқаны бірдей тест кескіндерінде салыстыру:

Бірінші нұсқа: conf=0.25, use_clahe=False.
Екінші нұсқа: conf=0.25, use_clahe=True.

data/tune/ — баптау жинағы. Оны қорытынды тестке қоспау керек.

results/threshold_comparison/ және results/clahe_comparison/
ішіндегі нәтижелер баптау жинағынан алынған.
Олар қорытынды тест метрикалары емес.

Тест кескіндерін модель болжамдарын қарамай тұрып белгілеу керек.
Анықтау саны precision немесе recall емес.
Қауіп туралы метрикаларды есептеу үшін модельмен бірге
3-қатысушының is_danger() функциясы қажет.

Бөлек тест жинағындағы қорытынды метрикалар әлі есептелген жоқ.

4. Бақыланған қателер мен шектеулер

Қара-ақ түнгі суреттегі ит CLAHE-мен де, онсыз да анықталмады.
Тұманды суреттегі өрт гидранты person деп қате белгіленді.
Кейбір көліктерде қайталануы ықтимал жақтаулар бар.
CLAHE жақтаулар санын өзгерткенімен, бұл сапаның жақсарғанын дәлелдемейді.

Қосымша фотосуреттердің дереккөздері, пайдалану шарттары және
тест жинағынан бөлек екені деректерге жауапты қатысушымен
толықтырылып, расталуы керек.

5. Қайта іске қосу

Python 3.10.11 ортасында тексерілді.

Жоба бумасында, іске қосылған виртуалды ортада орындалатын командалар:

python -m pip install -r requirements.txt
python compare_thresholds.py
python compare_clahe.py

Салыстыру үшін data/tune/frames/ ішіндегі кескіндер қажет.

Басқа компьютерде орнату және іске қосу әлі тексерілген жоқ.
3-қатысушы Streamlit пен интерфейстің басқа тәуелділіктерін
ортақ requirements.txt файлына қосуы керек.
