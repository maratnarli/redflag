# Постановка задачи

## Проблема

Препятствия на дороге (животные, люди, транспорт) опасны, если водитель замечает их слишком поздно. Ночью и в тумане видимость хуже, поэтому качество их обнаружения нужно проверять отдельно для каждых условий.

## Решение

Веб-прототип на Streamlit, который на записанном видео находит животных, людей и транспорт с помощью готовой модели YOLOv8n и показывает предупреждение.

## Ожидаемый результат

- Работающий прототип, который обрабатывает записанное видео и показывает предупреждения.
- Результаты тестов для дня, ночи и тумана: precision, recall и матрица ошибок.
- Описание ограничений прототипа по итогам тестов.
