Уақыт осы компьютердің CPU-ына байланысты, оны тек екі модельді өзара салыстыру үшін қолданыңыз.

## Қорытынды

- Recall екі модельде бірдей: 80% (10 қауіпті кадрдың 8-і табылды, тұманда бірдей 2 кадр өткізілді).
- YOLOv8s күндіз 2 артық жалған ескерту берді (`day_p_10`, `day_p_12`, екеуінде де person), сондықтан precision 57.1%-дан 50.0%-ға төмендеді.
- YOLOv8s CPU-да шамамен 2 есе баяу жұмыс істейді (бір кадрға ~47 мс, YOLOv8n ~25 мс).
- Сондықтан негізгі модель ретінде YOLOv8n қалдырылды. Қателердің негізгі себебі модель өлшемінде емес, ескерту логикасында (`src/alert.py`) және деректердің аздығында.
- Тест жинағы шағын (оң мысалдар 10), сондықтан бұл салыстыру тек осы жоба жағдайында ғана қорытынды жасауға мүмкіндік береді.
